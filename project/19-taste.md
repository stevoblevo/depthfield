# Taste

A page made with this kit should read as made, not generated. These are the tells that make a page look like a model wrote it, each from a real review, and `Depthfield.taste()` checks for them (Taste).

## Where the tells come from

Maesage Study 03 (November 2026) was competent and correct and still read as generated. Its reviewer asked why, and every answer was a pattern you can name:

| The tell | What it looked like | What to do instead |
|---|---|---|
| The showroom | a faceless render on a seamless backdrop, a product presented instead of used | draw the thing in use, or draw it so it can answer the hand |
| The frame | masthead, big headline, a bordered app frame with tabs, a two-thirds and one-third settings sidebar, a poetic closer | one scene; the first gesture in the first screen; settings in a sheet |
| The mode stack | five rows of segmented switches | fold modes into what happens; keep two switches at most |
| The inventory | the same six choices shown four times: on the art, as chips, as tiles, as a list | show a choice once, where it is used |
| Identical tiles | six tiles each saying "CHOOSE NEXT" | let each choice look like what it is |
| Eyebrow flood | small letter-spaced capitals over everything | one eyebrow per chapter, numbered |
| The italic second line | "Touch becomes / *a place.*" three times on one page | one emphasized word, or none |
| Slogans | "The cloth becomes a surface. The table becomes a world." | the owner's own words, quoted |
| The diminutive | "a little choreography", "a little feint", "a little world" | say a size once, when it is a size |
| The stock face | DM Sans beside a familiar serif | the kit's faces; Anybody when width can mean something |

## Rules

- Use the owner's words. A line someone actually said ("one lays on the table and the other… plays") beats any slogan written for them.
- The first screen answers a hand: something to pull, press, drag or throw, above the fold.
- One scene, not a dashboard beside a picture. The picture is the interface (The world); settings live in a sheet.
- Show each thing once, where it is used. If a choice must also be reachable as a list (it must), make the list the index, not a second control panel.
- Let materials answer differently: light asks, pigment remembers (Threads and light); reflective things dim with the room, emissive things do not.
- Name what is synthetic, inferred or scripted in plain words, once, where it is shown.

## Checking a page

1. Open it with `?df-taste`, at desktop and phone width, in its night face and in `contrast`.
2. Fix every `warn`. Read every `info` and keep it only if you can say why.
3. Then ask a person. The linter finds tells; it cannot find taste.
