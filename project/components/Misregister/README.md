# Misregister

Two print plates that slipped: cyan to one side, magenta to the other, so a word looks run off a cheap press.

**Provide** `class="hmp-misreg"` on a display heading or a link's label; it slips further when pointed at or focused. `tex-misreg` sets the slip (2.5 px).

- For display type only. Body text with misregistration is hard to read.
- High contrast prints it clean.

**Accessibility**: the colour fringes are text shadows; the glyphs themselves stay solid ink.
