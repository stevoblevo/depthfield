# Tape

A strip of masking tape holding a card or a picture to the page.

**Provide** `<span class="hmp-tape hmp-tape--tl" aria-hidden="true"></span>` inside a positioned card; corners `--tl`, `--tr`, `--bl`, `--br`, or `--top` across the top edge.

- Two pieces at most per card, on corners that are not over words.
- It is translucent: what is under it shows through.

**Accessibility**: decorative, always `aria-hidden`.
