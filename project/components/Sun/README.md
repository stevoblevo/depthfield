# Sun

The banded disc at the horizon: acid light at the top, tangerine, then magenta, cut by bars that thin toward the bottom.

**Provide** `<span class="hmp-sun" style="--sun:320px" aria-hidden="true"></span>`, usually as the first child of a Horizon (see GridFloor), where it sits on the horizon line by itself. `--sun` sets its width.

- One sun a page. It is art: no words on it, nothing to press.
- Zine prints it flat magenta; High contrast prints it in ink.

**Accessibility**: decorative, so `aria-hidden="true"`. It does not move.
