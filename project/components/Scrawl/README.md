# Scrawl

Marker notes in the margin, written by the people who made the page: an aside, a correction, an arrow at the thing that matters.

**Provide** `<p class="hmp-scrawl">← this is a website. it finds people work.<small>yes, really. — D.</small></p>`; `hmp-scrawl--cyan` for a second voice. `--scrawl-size` sets the size (20 px).

- In the margin or beside a heading, never inside a paragraph. Short: one line, maybe two.
- Sign it when a named person says it. Scrawl is a person talking, not the brand.

**Accessibility**: it is text in reading order; put it after the thing it comments on. The marker face is for a few words, never for instructions.
