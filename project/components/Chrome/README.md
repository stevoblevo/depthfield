# Chrome

Liquid-metal type for one display line: the dusk reflected in chrome, with a slow light passing over it.

**Provide** `<h1 class="hmp-chrome hmp-display-xl">Strange work</h1>`. Chrome reads the `chrome-1` to `chrome-5` tokens, so each theme has its own metal; High contrast and forced colours print it as plain ink.

- One or two chrome lines a page, at 32 px or more, on the dusk band or the void. Never body text, never a button label.
- The light passes over it every `dur-sheen` (7 s). Reduced motion, or the page's motion switch, holds it still.
- Zine prints it with a hard ink shadow instead of a glow.

**Accessibility**: the text is real text, selectable and read aloud. The gradient sits on the glyphs only; a 2 px abyss shadow keeps the edge readable against the band.
