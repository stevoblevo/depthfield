# Button

A control slapped onto the page: heavy capitals on acid with a hard shadow that presses in when you push it; a quiet ghost in monospace for the rest.

**Provide** `<button class="hmp-btn">Post a gig</button>`; `hmp-btn--accent` for the one main action in the accent; `hmp-btn--ghost` for secondary actions; `hmp-btn--sm` for tight rows. `aria-pressed="true"` fills a toggle with the accent.

- One loud button per region. Everything else is a ghost.
- Labels say what happens: "Post a gig", "Read the journey", never "Learn more".

**Accessibility**: 44 px tall at least, a 3 px focus ring in `focus`, text at 4.5:1 or better in every theme. The press is movement only; nothing depends on it.
