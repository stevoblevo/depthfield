# Stamp

A rubber mark: a word or two in spaced monospace capitals inside a double border, struck at an angle in the accent.

**Provide** `<span class="hmp-stamp">approved</span>`; `hmp-stamp--cue` stamps in the cue colour (for something found or done).

- Stamps state a status: approved, sold out, not the live site, checked. One per card.
- On Zine it multiplies into the paper like real ink.

**Accessibility**: the word is text and is read. A stamp never carries information that is not also said plainly nearby.
