# Type

Five open-licence families, all from Google Fonts, replacing Kit v0's system stacks (Impact, Arial Black and Comic Sans), which looked different on every machine.

| Family | Token | Face | For |
| --- | --- | --- | --- |
| Display | `--font-display` | Archivo Black | Display lines, stickers, buttons, card titles |
| Condensed | `--font-condensed` | Archivo Narrow | Tight labels, tables, the bar on a phone |
| Sans | `--font-sans` | Archivo | Reading and the interface |
| Mono | `--font-mono` | Space Mono | Stamps, the ticker, labels, numbers |
| Hand | `--font-hand` | Permanent Marker | Scrawl, and nothing else |

## Styles

`hmp-display-xl` (56 to 128 px), `hmp-display-l` (40 to 76 px), `hmp-display-m` (28 to 44 px), set in capitals and balanced; `hmp-title` (22 px bold), `hmp-lede` (20 px), `hmp-body` (17 px), `hmp-small` (14 px); `hmp-label` (12 px spaced mono capitals); `hmp-scrawl-text` (22 px marker).

## Rules

- Running text is Archivo at 17 px or more, at most 66 characters a line, never turned, never chrome, never misregistered.
- Capitals belong to display lines, stickers, stamps and labels.
- One chrome line, maybe two, a page.
